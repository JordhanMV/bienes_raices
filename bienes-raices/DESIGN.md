## Brand & Style

The design system embodies an editorial, high-end architectural perspective tailored for premier residential acquisition, luxury rentals, and bespoke land investments. The platform projects authority, precision, and visceral excitement. Real estate transactions at this level are aspirational; the interface acts as a cinematic frame, prioritizing imagery and structured data without visual clutter.

The visual direction merges **High-Contrast Minimalism** with **Frosted Glassmorphism**:
- Striking contrast anchored by pure crimson accents against deep slate and pristine white backdrops.
- Precision lines, generous spatial volume, and structural hierarchy inspired by modern architectural blueprints and high-end monographs.
- Translucent surface floating layers (glassmorphic overlays) to support rich photo-centric storytelling, interactive map contexts, and contextual property badges.

## Colors

The palette leverages high-contrast tension between functional architectural neutrals and an intense crimson focal point.

- **Primary (`#DC2626`)**: Vibrant crimson used selectively for primary calls to action, active map pins, key availability status, and primary highlights. Never over-saturate large layout containers with primary red; use it to guide focus.
- **Secondary (`#0F172A`)**: Deep slate charcoal providing typographic weight, dominant header surfaces, footer structures, and sharp contrast elements.
- **Tertiary (`#BE123C`)**: Deep ruby tone designated for interactive hover states, saved/favorite iconography, and verified premier property badging.
- **Neutrals**:
  - `Canvas / Pure White`: `#FFFFFF` for primary cards, main background planes, and modal surfaces.
  - `Subtle Surface Grays`: `#F8FAFC` for page canvas backgrounds, `#F1F5F9` for secondary card structures and neutral input fields.
  - `Borders & Rules`: `#E2E8F0` for hairline outlines and structural divider rules.
  - `Text Muted`: `#64748B` for secondary specs (dimensions, room counts, location tags) and metadata.

## Typography

The typography system pairs geometric presence with high-density legibility:

- **Headlines & Display (Plus Jakarta Sans)**: Conveys architectural geometry, structural confidence, and premium modernism. Tighter letter spacing on display tiers mirrors contemporary architectural print publications.
- **Body & Specs (Inter)**: Provides pristine clarity across varying screen scales, crucial for real estate data sheets (square footage, lot ratios, price calculations, and mortgage estimates).
- **Labels & Badges (Plus Jakarta Sans)**: Rendered in semi-bold and bold weights with subtle tracking to maintain legibility on translucent media tags and interactive filter buttons.

## Layout & Spacing

The layout utilizes a structured 12-column grid system calibrated to balance heavy imagery against dense spatial attributes:

- **Desktop (>= 1280px)**: 12 columns with `margin: 3rem` (max content container width `1440px`), `gutter: 1.5rem`. Split-view layouts (Map + Property Feed) allocate 5 columns to scrollable feed and 7 columns to persistent interactive map canvas.
- **Tablet (768px - 1279px)**: 8 columns with `margin: 2rem`, `gutter: 1.25rem`. Toggle switch activates between map and list views.
- **Mobile (< 768px)**: 4 columns with `margin: 1.25rem`, `gutter: 1rem`. Floating sticky search controls and single-column property card stacks.
- **Spacing Rhythm**: Element gaps strictly adhere to the 4px/8px modular base scale (`space-xs` through `space-2xl`) to ensure tight architectural alignment across listing grids, gallery ribbons, and property feature matrices.

## Elevation & Depth

Visual hierarchy combines light atmospheric shadows with glassmorphic layers to keep UI elements floating gracefully over architectural photography:

- **Surface Glass (Level 0 - Translucent)**: `background: rgba(255, 255, 255, 0.72); backdrop-filter: blur(16px); border: 1px solid rgba(255, 255, 255, 0.4);` Used on floating search bars, image carousel navigation pills, and photo overlay badges.
- **Dark Surface Glass (Level 0 - Contrast)**: `background: rgba(15, 23, 42, 0.78); backdrop-filter: blur(12px); border: 1px solid rgba(255, 255, 255, 0.12);` Used for pricing overlays and media badges directly over bright exterior imagery.
- **Level 1 (Property Cards & Inputs)**: Flat pure white surface bounded by a subtle border (`1px solid #E2E8F0`) with ambient shadow `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`.
- **Level 2 (Hovered Cards & Dropdowns)**: Elevated depth using `0 10px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.03)`.
- **Level 3 (Modals & Persistent Drawers)**: High-altitude surface with `0 25px 50px -12px rgba(15, 23, 42, 0.22)`.

## Shapes

The design system employs a **Rounded** shape language (`roundedness: 2`), balancing architectural rigor with modern consumer accessibility:

- **Standard Cards & Form Containers**: `0.75rem` to `1rem` (`rounded-lg`) corner radii, introducing smooth modern contours without feeling bubbly.
- **Filter Chips, Action Badges, and Micro-controls**: `9999px` (Full Pill) for contextual tags (e.g., "En Venta", "Preventa", "Lote Residencial") to create immediate visual separation from rectangular architectural photo ratios.
- **Media Containers**: `0.75rem` corner radius on gallery viewports and property card preview slots with `overflow: hidden` to frame imagery neatly.
- **Inputs & Dropdown Triggers**: `0.5rem` to `0.75rem` for ergonomic touch targets.

## Components

### Buttons
- **Primary**: Background `#DC2626`, text `#FFFFFF`, font weight 600. Hover: `#BE123C` with smooth 150ms ease transition. Active: slight scale down (0.98).
- **Secondary (Outline)**: Background transparent, border `1.5px solid #0F172A`, text `#0F172A`. Hover: background `#0F172A`, text `#FFFFFF`.
- **Ghost / Glass**: Background `rgba(255, 255, 255, 0.85)` with backdrop blur `12px`, border `1px solid rgba(226, 232, 240, 0.8)`, text `#0F172A`.

### Property Cards
- Structured compound layout: Aspect ratio 16:10 image header with top-left glassmorphism badge (`rgba(15, 23, 42, 0.75)`) displaying category ("Venta", "Renta", "Terreno") and top-right favorite heart button.
- Body container: Crisp `#FFFFFF` card, subtle `#E2E8F0` border, `space-md` internal padding.
- Price displayed in `headline-md` weight using `#0F172A`, alongside property specs row (Bedrooms, Bathrooms, Sq Footage/M²) styled with minimalist icons and `#64748B` typography.

### Filter Bar & Search Controls
- Floating composite search bar: Integrated segmented tabs ("Comprar", "Rentar", "Desarrollos") styled with pill active indicators.
- Quick filter chips: Horizontal scrolling row with active state highlighted via `#0F172A` background and `#FFFFFF` text; inactive state styled with `#F1F5F9` background and `#64748B` label.

### Inputs & Selectors
- Background `#FFFFFF` or `#F8FAFC`, border `1px solid #E2E8F0`, padding `0.75rem 1rem`. Focus state: border-color `#DC2626` with `0 0 0 3px rgba(220, 38, 38, 0.12)`.

### Badges & Status Chips
- **Hot Property / Exclusive**: Background `rgba(220, 38, 38, 0.1)`, text `#DC2626`, border `1px solid rgba(220, 38, 38, 0.2)`.
- **Verified Listing**: Background `rgba(15, 23, 42, 0.06)`, text `#0F172A`, icon checkmark.
